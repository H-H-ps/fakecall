# مكالمة وهمية — FakeCall

تطبيق أندرويد ترفيهي: زر في الإعدادات السريعة (Quick Tile) يعرض شاشة مكالمة واردة تشبه تطبيق الهاتف.

## التشغيل
1. افتح Android Studio (نسخة حديثة) ← File > Open ← اختر مجلد `FakeCall`.
2. انتظر مزامنة Gradle (إذا اقترح ترقية AGP/Gradle/Kotlin فوافق).
3. شغّل التطبيق على هاتفك (Android 9 أو أحدث).
4. من التطبيق: امنح الأذونات، ثم اضغط «أضف الزر إلى الإعدادات السريعة».

## الميزات
- تعديل الاسم والصورة، وعدة جهات اتصال مع اختيار الفعّالة.
- تأخير قبل الرنين: فوراً / 5 / 10 / 30 ثانية.
- اختيار نغمة + اهتزاز.
- رنين 5 ثوانٍ (ثم مكالمة فائتة) — والرد يعطي شاشة مكالمة جارية 3 ثوانٍ ثم تنتهي.
- زرّا الصوت يُسكتان الرنين.
- لتغيير المدد: `Config.kt` ← `CallConfig`.

## ملاحظات
- الصورة الافتراضية: `res/drawable-nodpi/default_caller.jpg`.
- الاسم الافتراضي: «العفوية» (`Prefs.DEFAULT_NAME`).
